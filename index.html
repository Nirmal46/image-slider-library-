01 — ABOUT THE PROJECT

Wanderlust is a travel photography gallery that presents beautiful destinations through an interactive image slider.

HTML structures the webpage, CSS controls its appearance and responsive layout, and JavaScript manages image navigation, slide counters, navigation dots, and infinite looping.
